# Shop City Tycoon

A pastel, low-poly Roblox business tycoon. You buy shops around a living city, step inside
your own private copy of each one, upgrade it until the room physically changes, hire staff,
watch real customers walk in from the street, and play a hands-on mini game at the counter
to earn extra cash. When you own enough shops you can Prestige for a permanent income boost.

- **Roblox place:** "wwww", place ID `113030321095675` (game ID `10777368481`), edited with Team Create
- **Working name in code:** City Business Simulator. **Chosen title:** Shop City Tycoon
- **Language:** server-authoritative `--!strict` Luau

> The code in this repo is the **source of truth for scripts**. The 3D city itself (the
> `Workspace.City` folder) lives in the Roblox place; it is generated by the edit-time tool
> `src/ServerStorage/DevTools/CityBuilder.luau` from `Shared/CityLayout.luau`.

### Testing in Studio

`Config.STUDIO_TEST_MODE` is on: in a Studio playtest nothing is loaded or saved and you start
with $1B, so buy shops and play the mini games freely. Live servers ignore it. Set it to
`false` only if you need to playtest with your real save.

## Working on it

**In Roblox Studio (simplest):** open the place with Team Create and edit scripts there.
When you change scripts in Studio, copy the changes back into this repo so it stays current.

**From this folder with Rojo (recommended for two people):**

1. Install [Aftman](https://github.com/LPGhatguy/aftman), then run `aftman install` here.
2. Install the Rojo plugin in Studio.
3. Run `rojo serve`, open the place in Studio and press **Connect** in the Rojo plugin.
4. Edit files in `src/`; Rojo pushes them into Studio live. Commit and push with git.

The project file only manages the script folders above (`$ignoreUnknownInstances` is on), so
it leaves the city, the `Remotes` folder and everything else in the place alone.

## How the game is built (short version)

- **Server owns everything that matters.** Money, customers, purchases, prestige and mini
  game rewards are all decided on the server. Clients only send requests (through
  `Services/Net`, which rate-limits every remote) and draw what the server says.
- **Services** (server) talk through one shared registry set up in `Main.server.luau`.
- **Controllers** (client) are booted by `ClientMain.client.luau` in a fixed order and also
  share one registry.
- **Interiors are private.** Each player gets their own copy of a business interior, built
  on their client only, so upgrades show up instantly and nobody else sees it.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for every script.

## Collaborators

This repository is public, so anyone can read and clone it. To let a friend **push**
changes: on GitHub open **Settings > Collaborators > Add people** and enter their GitHub
username; they accept the invite from their email or notifications.
For Studio access, also add them to the experience's Team Create.
